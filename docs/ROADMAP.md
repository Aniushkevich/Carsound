# CAR VOICE — Roadmap

## 1. Сохранение исходников
- Импортировать актуальный UI Kit, логотип, баннер и все утверждённые версии главной страницы.
- Сохранить существующие HTML-макеты без изменения в `legacy/`.

## 2. Фронтенд
- React + TypeScript + Vite.
- Переиспользуемые компоненты и дизайн-токены.
- Главная, каталог, автоакустика, адаптивная навигация.
- Сворачивание раскрытого раздела по повторному нажатию.

## 3. Магазин
- Категории, фильтры, поиск, сравнение, карточки товаров, корзина.
- Серверная часть, остатки, заказы, оплата и доставка для Беларуси.

## 4. Портал и студия
- Услуги установки и настройки, статьи, обзоры, SQ/SQL и сообщество.
